# 3D 맵과 리본이 (2026-09-18)

TV 화면은 **블렌더로 렌더한 방 사진 위에 three.js 로 리본이를 겹친 것**입니다. 방·가구·리본이 모델은 **Character_Creator**(블렌더, `E:/Project/Character_Creator`)에서 만들고, 이 프로젝트는 가져다 씁니다.
아이들은 화면에 그리지 않습니다. 리본이가 방을 돌아다니다가 부르면 반응합니다.

## 가져오기 / 갱신

```
python tools/sync_world.py                       # 모델·카탈로그·블렌더 스크립트
python tools/sync_world.py --doll                # + 인형 고화질 다시 내보내기 (Windows 블렌더)
python tools/sync_world.py --layouts --artworks  # 배치·그림까지 (기존 배치는 history 로 보관)
```

Character_Creator 에서 가구 모양이나 인형을 고쳤으면 그쪽에서 "블렌더 미리보기"(카탈로그 내보내기)를 한 번 한 뒤 위 명령을 다시 돌리고 `npm run build`.
경로가 다르면 `--src` 또는 환경변수 `CHARACTER_CREATOR`.

배치 파일(`data/world/*.json`)은 기기마다 따로라 git 으로 오지 않습니다. 방 크기를 바꾼 커밋을 받은 뒤에는
이미 쓰던 배치에서 벽에 붙어 있던 가구가 떠 보일 수 있습니다. 미술실을 넓힌 커밋(네 귀퉁이 기둥)에는
`python tools/widen_layout.py` 를 한 번 돌리면 맞습니다 (`--dry` 로 먼저 확인).

> Character_Creator 의 `tools/layout_server.py` 도 기본 포트가 8765 라서 리본 서버와 동시에 켜면 충돌합니다. 둘 중 하나를 `--port` 로 바꾸세요.

## TV 배경 렌더 (`server/ribbon/world_render.py`)

1. 맵 편집기에서 저장하면 서버가 그 방을 블렌더 헤드리스로 렌더한다 (`RIBBON_RENDER_AUTO`, 한 번에 하나, 렌더 중 또 저장하면 끝난 뒤 한 번 더).
   편집기의 "🎬 배경 렌더" 로 직접 돌릴 수도 있다. 서버를 켤 때 렌더가 없거나 옛 배치인 방도 렌더한다.
2. 결과: TV 시점 PNG (Cycles, AgX, 기본 1920x1080) + "부르면 오는 자리" 눈높이의 360° HDR.
   미술실은 **시간대마다 한 장씩** 렌더한다 (`tools/blender/phases.py`: 일출 5시 / 아침 7시 / 낮 11시 / 일몰 17시 / 밤 20시).
   방을 한 번만 짓고 조명만 바꿔 차례로 찍는다. 창이 없는 전시장은 한 장뿐.
   TV 는 제 시계를 보고 1분마다 지금 시간대의 배경·환경광으로 갈아 끼운다 (방은 그대로).
3. TV 는 **렌더에 쓴 배치**로 가구 모델을 "깊이만 그리는 가림막"으로 두고(가구 뒤로 가면 가려짐),
   바닥에는 그림자만 받는 판을 깐다. 리본이는 HDR 환경광 + 천 재질(sheen), 톤매핑은 블렌더와 같은 AgX.
   카메라가 블렌더와 같아야 해서 화면은 16:9 고정 (남는 곳은 검은 띠).
4. 렌더가 끝나기 전까지 TV 는 옛 배경과 옛 배치 그대로. 블렌더가 없으면 방까지 실시간 3D 로 그린다.

### 빛
- 낮에는 **왼쪽 창으로 드는 자연광**이 천장 매립등(네 귀퉁이 LED 평판)보다 세고, **일몰을 지나면 뒤집혀** 실내 조명이 방을 밝힌다.
  시간대별 하늘빛·햇빛·천장등 세기·노출은 모두 `phases.py` 한 곳에 있다 (`sun` 대 `panel` 이 그 비율).
- 오른쪽 유리벽 밖은 **상가 복도**라 시간과 상관없이 늘 같은 밝기다. 맞은편도 미술실과 같은 통유리벽에
  검은 시트지가 붙어 있고, 복도 천장 높이는 미술실과 같다 (다르면 유리벽 위에 띠가 생겨 어색하다).
- 조명 오브젝트는 카메라·유리 너머로 보이지 않게 해서(`visible_camera/transmission/glossy = False`)
  창에는 하늘빛만 비친다. 조명판이 하얗게 비치면 시간대가 구분되지 않는다.

## 아이 전시실 (`?mode=art`)

관리자 페이지에 있는 아이마다 전시실이 하나씩 있습니다. 방 id 는 `kid-<아이 id>` 입니다.

- **가구와 방 모양**은 전시장(`gallery`) 것을 그대로 빌려 씁니다. 아이마다 다른 것은 **벽에 걸린 작품뿐**입니다.
  (배치 파일 `data/world/kid-<아이 id>.json` 에는 `arts` 만 들어 있습니다.)
- **배경 렌더는 아이 수와 상관없이 한 장**입니다. 그림을 뺀 전시실을 `kidbase` 로 렌더해 두고 모두 같이 씁니다.
  걸린 작품은 TV 가 그 배경 위에 three.js 로 그립니다(`render.arts_live`). 그래서 작품을 올려도 렌더를 기다리지 않습니다.
- 꾸미기 페이지 `/?mode=art&kid=<아이 id>` (관리자 페이지에서 아이를 고르면 버튼이 있습니다):
  - 작품 사진을 올리면 **배경을 지우고**(가장자리에서 같은 색으로 이어진 곳을 지우고 남은 부분에 맞춰 자름) 작품만 남깁니다.
  - 벽을 정면에서 본 그림에서 **끌어서 옮기고, 모서리를 끌어 크기를 바꿉니다. 비율은 고정**입니다.
  - 저장하면 그 아이 전시실의 `arts` 만 바뀝니다.
- **TV 에서 보기**: `POST /api/world/visit {kid_id, seconds}`. 그 전시실로 갔다가 `seconds` 뒤에 원래 방(교실)으로 돌아옵니다.
  평소 TV 는 교실이고, 요청했을 때만 전시실을 보러 갑니다.
- 작품 사진은 지금까지처럼 `data/artworks/` 에 모이고, `index.json` 의 `kid_id` 로 누구 것인지 구분합니다.

## 리본이 행동 (`client/src/tv/brain.ts`)

| 상황 | 행동 |
|---|---|
| 평소 | 방 안 빈 곳(가구·벽·기둥을 피하고 **몸 전체가 TV 화면에 보이는 곳**)으로 걸어가 잠깐 쉬기, 걸린 그림 앞에 가서 구경, 가끔 TV 쪽으로 손 흔들기 |

| 듣는 중 / 생각 중 | 머리 위 👂 / 💭, 고개 갸웃. 카메라 폰이 얼굴을 보면 그 얼굴 쪽을 봄 |

| 인사 | Greet 액션에서 오른팔 트랙만 씀 (고개 갸웃·몸 흔들기 없이 손만 흔들기) |

## 표정

얼굴은 눈·볼·입·미간 주름 조각으로 만든다 (`client/src/tv/face.ts`, `mouth.ts`).

- **눈**: 조각을 눌러 찌그러뜨리고 기울인다 (감음·^^·크게·실눈). 깜빡임도 여기서.
- **입**: 모양별 조각이 인형에 들어 있고(`Mouth_*`) 하나만 켠다. 구멍을 뚫지 않고 얼굴에 붙는 방식이라 표정마다 바꿀 수 있다.
  모양은 Character_Creator `doll.py` 의 `build_mouths()` 에서 만든다: 다문 ⌣ / 일자 / 삐죽 / 꺾인 선 / 물결 / 꾹 다문 / 처진 입 / 울상 / 동그라미 / 웃는 입 / 크게 벌린 입(+혀).
- **미간 주름**(`Furrow_L/R`): 고민할 때만 켠다. `doll.py` 의 `build_brow_furrow()`.
- 입 모양을 새로 만들거나 고치면 `doll.py` 를 다시 돌려 `doll.blend` 를 만들고, `python tools/sync_world.py --doll` 로 내보낸다.
  휘거나 뒤집은 모양은 면이 뒤집혀 화면에서 사라지므로 `face_forward()` 로 앞을 향하게 맞춘다.

| 상황 | 표정 |
|---|---|
| 평소 | 기본 / 가끔 웃음·갸웃 |
| 부르면 | 웃음 (3초) |
| 듣는 중 | 기본 + 끄덕임 |
| 생각 중 | 고민 (일자 눈·미간 주름·꺾인 입), 6초 넘으면 걱정 |
| 말하는 중 | 말하는 표정. 소리가 크면 입을 크게, 작으면 작게 |
| 그림 앞 | 갸웃 |
| 의자에 앉아 | 기본 / 가끔 졸림 |
| 아이 입장 | 놀람 → 웃음 (+박수·깡충) |
| 아이 하원 | 시무룩 (3초) |

이 밖에 부끄러움·울상·뾰로통도 있고 필요할 때 붙이면 된다 (`EXPRESSIONS`).

## 동작 (`tools/blender/doll_actions.py`)

doll.blend 에는 걷기·인사만 있어서, 내보낼 때 짧은 동작들을 만들어 넣는다. 고치면 `python tools/sync_world.py --doll` 로 다시 내보낸다.

| 동작 | 언제 |
|---|---|
| Wave (Greet 오른팔) | 부를 때, 가끔 TV 쪽으로 |
| Nod / Tilt | 듣는 중 맞장구, 궁금할 때 |
| LookUp | 생각하는 중 |
| Sway / Stretch | 가만히 있을 때 (심심함·기지개) |
| Point | 그림 앞에 섰을 때 |
| Clap / Jump | 아이가 들어왔을 때 (kid.enter) |
| Sit (반복) | 의자에 앉아 쉴 때 (12~30초) |
| Shake | (아직 안 씀) 아니라고 할 때 |

만들 때 주의: 팔을 X 축 **+** 로 돌리면 몸 뒤로 가서 큰 머리에 가려 안 보인다. 앞쪽(-X)으로 올리고 Z 로 벌린다.

### 의자에 앉기

어린이 높은 의자(좌판 52cm)와 윈저 의자(46cm)에 앉는다. 좌판 높이는 `client/src/world/types.ts` 의 `SEATS` 에 적어 두었고,
값은 Character_Creator `room_map.py` 의 의자 만들기 함수(`seat_z`)에서 가져온 것이다. 의자를 고치면 이 값도 맞춰야 한다.
앉을 때는 몸만 좌판 높이로 올리고 그림자는 바닥에 남긴다. 의자 앞이 책상에 막혀 있으면 옆이나 뒤에서 다가간다.
부르면 먼저 일어선다.
| 대화 끝 | `return_after_s`(기본 8초) 뒤 다시 돌아다님 |

관리자 페이지에서 끌 수 있습니다: 돌아다니기(끄면 자리에 서 있음), 걷는 속도, 다시 돌아다니기까지 시간.
겉모습은 원피스/투피스와 머리·리본·원피스(치마)·블라우스 색 (`RibbonLook`, glb 재질 이름으로 찾음).
